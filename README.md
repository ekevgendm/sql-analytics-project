# SQL Analytics Project

A small SQL project built with PostgreSQL to practice data analysis on a sample e-commerce database.

## Database

The project contains data about:

- employees and departments
- customers
- products
- orders
- order items

## SQL topics

The project covers:

- SELECT and filtering
- sorting and grouping
- JOINs
- aggregate functions
- subqueries
- CTEs
- window functions

## Project structure

```text
sql/
├── 01_database_setup.sql
├── 02_basic_queries.sql
├── 03_joins.sql
├── 04_aggregations.sql
├── 05_subqueries_and_cte.sql
└── 06_window_functions.sql
```

## Examples of analysis

The project includes queries for:

- counting orders by customer
- calculating customer revenue
- calculating revenue by product category
- finding employees with above-average salary
- calculating average salary by department
- ranking employees by salary within departments
